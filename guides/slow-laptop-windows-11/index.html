How to Fix a Slow Laptop on Windows 11 (8 Steps)

Quick answer: Restart the laptop, then disable unnecessary startup apps in Task Manager and free up disk space. These two steps fix most slow Windows 11 laptops.

A slow laptop is usually caused by too many background programs, a nearly full drive or outdated software. These steps go from easiest to most involved.

1. Restart your laptop

Restarting closes stuck processes and clears memory. Use Restart, not Shut down, because Windows 11's fast startup can keep old problems alive.

2. Find what is using your resources

Press Ctrl + Shift + Esc to open Task Manager. Sort by CPU, Memory and Disk. If one app uses most of a resource, close it or uninstall it.

3. Disable startup apps

In Task Manager, open the Startup apps tab. Right-click apps you don't need at boot and choose Disable. Chat apps, game launchers and updaters are common culprits.

4. Free up storage

Go to Settings > System > Storage and turn on Storage Sense. Delete temporary files and uninstall programs you no longer use. Try to keep at least 15% of your drive free.

5. Install Windows and driver updates

Open Settings > Windows Update and install everything available. Also check Advanced options > Optional updates for driver updates.

6. Scan for malware

Open Windows Security > Virus & threat protection and run a Full scan. Malware and unwanted browser extensions can slow a laptop a lot.

7. Change your power mode

Go to Settings > System > Power & battery and set Power mode to Best performance while plugged in. Battery saver mode deliberately slows the laptop.

8. Upgrade hardware if needed

If the laptop is still slow, check what you have. A laptop with a hard drive (HDD) feels much faster after switching to an SSD. A laptop with 4 GB of RAM benefits from upgrading to 8 GB or 16 GB if the model allows it.

Tip: Back up your files before making big changes. If nothing helps, Settings > System > Recovery > Reset this PC is the last resort.
